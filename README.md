# 强化学习系列

> 概念 · 动手 · 算法 · 大模型

智能体做的事情，说起来只有一句：不知道答案，先做，看结果，再调整。这套书按四册展开同一件事。

第一册把概念和全景讲清楚，第二册在游戏里真的训练起来，第三册拆开算法的推导与实现，第四册回到大模型怎样用强化学习学会推理。

## 怎么读

- 四册可以按顺序读，也可以从最关心的一册开始。
- 刚接触强化学习：读概念篇，不写复杂公式。
- 想让程序真的学会一件事：读动手篇，从 CartPole 到 PPO。
- 要读懂论文、自己改算法：读算法篇。
- 关心大模型训练：读大模型篇，RLHF、DPO、GRPO 与 RLVR。
