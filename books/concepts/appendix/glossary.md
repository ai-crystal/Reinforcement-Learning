基础概念
:::

| 词 | 一句话解释 |
| --- | --- |
| 智能体 | 做决定的那一方，可以是程序、机器人或一个模型 |
| 环境 | 智能体之外的一切，按自己的规则变化 |
| 状态 | 智能体做决定时能依据的全部信息 |
| 动作 | 智能体能做的事，有离散和连续两种 |
| 奖励 | 环境给出的一个数，定义了什么叫做得好 |
| 回合 | 从开始到终止的一段过程 |
| 折扣因子 | 决定智能体多看重未来，越接近 1 看得越远 |
| 回报 | 一段过程里奖励的折扣累加 |
| 价值 | 从某个状态出发，未来能拿到的回报的期望 |
| Q 值 | 在某个状态下先做一个动作，之后的期望回报 |
| 策略 | 从状态到动作的对应关系，可以带随机性 |
| 探索 | 尝试没把握的选择，为了获取信息 |
| 利用 | 选择当前看起来最好的，为了拿到分数 |
| 稀疏奖励 | 大部分步骤没有反馈，只有少数时刻给分 |
| 泛化 | 在没见过的情形下也能表现正常 |

方法与算法
:::

| 词 | 一句话解释 |
| --- | --- |
| 信用分配 | 把最终结果分摊到中间每一步的决策上 |
| 在轨 | 学习和行动用同一个策略 |
| 离轨 | 学习和行动用不同策略，数据可以复用 |
| 经验回放 | 把过去的经验存起来，训练时随机抽取 |
| 目标网络 | 一份更新更慢的网络副本，用来稳定学习目标 |
| 自举 | 用自己的估计去更新自己 |
| 动态规划 | 已知环境的全部规则，反复代入贝尔曼方程求解 |
| 蒙特卡洛 | 走完整局，用实际拿到的回报去估计 |
| 时序差分 | 每走一步，用下一步的估计去更新当前估计 |
| Q 学习 | 用"当前奖励加下一步最大值"作为目标的价值算法 |
| 策略梯度 | 直接调整每个动作的概率，不经过打分再取最大 |
| 演员评论家 | 一个网络选动作，另一个网络评价当前状态 |
| 优势函数 | 某个动作比平均水平好多少 |
| 重要性采样 | 用旧策略的数据估计新策略的表现，需要修正比例 |
| PPO | 给策略更新加限幅的方法，大模型训练的主力 |
| 蒙特卡洛树搜索 | 把算力集中在有希望的分支上的搜索方法 |
| 自对弈 | 让智能体和自己或历史版本下棋，对手跟着一起变强 |
| 模仿学习 | 从专家示范里学，而不是从奖励里学 |
| 离线强化学习 | 只用一批固定数据学，不再和环境交互 |
| 域随机化 | 训练时随机化环境参数，让策略适应现实的不确定性 |
| 世界模型 | 学出来的环境模型，可以在里面想象着训练 |

大模型与前沿
:::

| 词 | 一句话解释 |
| --- | --- |
| RLHF | 用人类偏好训练奖励模型，再用强化学习调模型 |
| 奖励模型 | 学出来的打分器，输入一段回答，输出一个分数 |
| 偏好数据 | 同一个问题的两段回答，标注哪一段更好 |
| SFT | 监督微调，用高质量回答教模型怎么说话 |
| DPO | 直接用偏好数据优化模型，省掉奖励模型和在线采样 |
| 奖励黑客 | 智能体找到奖励的漏洞，优化了指标却背离了目标 |
| 对齐税 | 让模型更符合偏好，往往要牺牲一点别的能力 |
| 可验证奖励 | 能由程序自动判断对错的奖励，比如答案比对 |
| GRPO | 用同组回答的平均分做基准，省掉价值网络的算法 |
| 拒绝采样 | 生成多个回答，只保留正确的，用来做下一轮训练 |
| 蒸馏 | 用大模型生成的数据去训练小模型 |
| 过程奖励 | 不只看最终答案，给推理的每一步打分 |
| 测试时计算 | 在推理阶段多花算力，比如多采样几次再选 |
| Agentic RL | 训练会调用工具、连续做多步决策的模型 |
| 具身智能 | 有身体、能在物理世界里行动的系统 |
| 对齐 | 让模型的行为和目标符合人的意图，含义有好几层 |
| 评测污染 | 训练数据里混进了测试题，分数因此失真 |
