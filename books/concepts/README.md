# 概念篇 · 从老虎机到推理模型的全景图

> 《试错》第一册

这一册不写复杂公式，只把强化学习的每个词放回它要解决的问题里，再把今天还在用的方向走一遍。

读完能看懂一条技术新闻在说什么，也能把一个新名词放回它该在的位置。

## 这一册讲什么

先建立框架：智能体、环境、状态、动作、奖励，以及奖励来得太晚这个核心困难。然后讲怎么学：探索与利用、价值、策略。接着看真实案例，从 Atari、AlphaGo 到推荐、芯片和科学实验。再往后是大模型：RLHF、可验证奖励、会使用工具的智能体，以及这套方法的代价。最后把视角拉远，讲多智能体、模仿与离线、世界模型与具身智能、评测与安全，收在十个误解和读新闻的方法上。
