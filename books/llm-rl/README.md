# 大模型篇 · 从人类反馈到推理模型

> 《试错》第四册

这一册把强化学习放到语言模型上。状态是已经生成的文本，动作是下一个词，奖励来自人类偏好或者一段检查答案的程序。

同名的方法在这里换了样子。PPO 要同时放四个模型，DPO 把强化学习化简成一个分类问题，GRPO 干脆去掉价值网络，可验证奖励让推理能力第一次变成可以直接训练的东西。

## 五部分

第一部　把生成看成决策

1. 一个 token 就是一步动作
2. 奖励模型：把偏好变成一个分数

第二部　从反馈到偏好

3. PPO 训练大模型的工程现场
4. DPO：把强化学习化简成分类
5. 偏好优化的变体：IPO、KTO、ORPO、SimPO

第三部　可验证奖励与推理

6. RLVR：答案能检查时发生了什么
7. GRPO：去掉价值网络
8. R1 式训练：冷启动、拒绝采样与蒸馏
9. 测试时计算：采样、投票与搜索

第四部　边界与判断

10. 奖励黑客与对齐失败
11. Agentic RL：多轮、工具与环境
12. 对齐的代价：谄媚、退化与多样性

第五部　把方法落到工程

13. 预训练、SFT 与 RL 的分工
14. 奖励模型训练实战
15. PPO 实现：用 TRL 跑一遍
16. DPO 的数学细节
17. 可验证奖励的数据工程
18. 蒸馏与小模型复现
19. 评测、复现与收尾

## 关于时效性

这个方向变化很快。书里多讲机制、少讲数字，遇到具体模型的成绩只作为例子。稳定的东西是那套判断框架：奖励从哪来，样本从哪来，代价是什么。
