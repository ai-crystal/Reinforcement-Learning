# 动手篇

> 在游戏里训练一个会决策的程序

这一册把概念变成能跑的程序。从 CartPole 开始，自己写环境，用表格学会走路，再换成神经网络，一路做到 PPO，最后补上并行采样、连续动作和部署这些工程问题。

装环境、看接口、写环境、跑算法、画曲线、查问题，最后把训练好的策略存下来、跑起来、接进程序。每一章都有一个能单独运行的脚本，跑完把结果存成 JSON，插图脚本再从那里读数据。
