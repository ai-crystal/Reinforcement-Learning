## 函数逼近与致命三要素

表格方法的泛化能力是零。学到“这个格子往右走”，旁边那个格子还要重学一遍。

这句话听着夸张，算一下就知道了。一千个格子，每个都要单独学，每个至少要看几十次，才能把噪声平均掉。总共几万步的交互，还只是学会一个一千格的小问题。状态再多一倍，代价就翻一倍，没有任何摊销。

把表换成一个带参数的函数，这个问题就解决了。代价是引入了一堆新的不稳定，其中最要命的一组被称为致命三要素。这一章讲清楚它是什么，为什么会致命，以及工程上怎么绕开。

### 参数化的价值函数

把 $Q(s,a)$ 写成 $Q(s,a;\theta)$，$\theta$ 是参数。函数可以是线性的，也可以是神经网络。

更新时不再直接改某个格子的数，而是沿着梯度调整参数，让 $Q(s,a;\theta)$ 更接近目标 $y$。

$$
\theta \leftarrow \theta + \alpha\left[y - Q(s,a;\theta)\right]\nabla_\theta Q(s,a;\theta)
$$

注意这里没有对目标求导。目标 $y$ 也依赖 $\theta$，如果严格按均方误差求导，应该还有一项。忽略这一项的做法叫**半梯度**，它不保证收敛到真正的最小二乘解，但在实践中效果不错，而且计算量小。

这个“忽略”是后面很多问题的源头。

还有一个容易被混淆的点，半梯度不是写错了。初学者看到目标里含参数却不求导，第一反应是漏了一项，想补上。补上当然也可以，那是真正的梯度，代价是目标也在动，每一步的最优解也跟着变，收敛反而没有保证，计算量也翻倍。半梯度是故意丢掉那一项，换的是稳定性，不是精度。理解这个取舍，才不会被“该不该求真梯度”这个问题绕住。

### 线性函数逼近长什么样

神经网络之前，主流做法是线性。价值和特征的内积，参数就是权重。

$$
Q(s,a;\theta) = \theta^\top \phi(s,a)
$$

$\phi(s,a)$ 是人工设计的特征向量，$\theta$ 是要学的权重。表格是它的特例，特征是“当前状态动作对”这一位的指示函数，权重就是表里的那个数。

举一个具体的。五乘五的网格，如果用“横坐标、纵坐标、常数”三个特征，参数只有三个，二十五个格子共用。学一个格子的价值，会同时改到整行整列。这就是泛化，也是麻烦的开始。

特征的数量决定了能表达多复杂的函数。三个特征只能表达平面，网格的真实价值是个弯曲的曲面，平面拟合不了，无论怎么调权重都会有残差。这个残差叫逼近误差，它和算法无关，是表示能力的天花板。

神经网络做的事本质相同，只是特征由网络自己学，不再靠人手设计。代价是特征本身也在变，稳定性分析变得更难。

### 特征怎么设计

线性方法能不能用，八成取决于特征。几个常用的做法。

一是归一化。把每个特征缩到相近的范围，否则量级大的那一维会主导梯度，学习率对其他的维度来说要么太大要么太小。位置以米为单位，速度以每秒米为单位，两者数值差几个数量级，不归一化几乎学不动。

二是粗编码。把一个连续变量分成若干区间，每个区间一个特征，落在区间里就置一。分得粗一点，泛化强；细一点，精度高。这个方法比直接拿原始数值当特征好，因为它不假设线性关系。

三是瓦片编码。把粗编码叠几层，每层的分界错开，同一个变量同时在几层里被编码，再求和。效果是把分辨率抬高很多，代价是同样的精度需要更多特征。它在小规模连续控制里很好用，实现只有几行。

四是径向基函数。每个特征是一个中心点周围的隆起，距离越近响应越强。它给出平滑的泛化，代价是要选中心点，而且高维时需要的中心数指数增长。

四种做法的共同点是，它们都在回答“哪些状态应该像”。这个问题定错了，后面所有算法都救不回来。

### 三要素

致命三要素指的是三件事同时出现。

**函数逼近**。用参数化的函数代替表格。

**自举**。更新目标里包含自己的估计，比如 $r + \gamma \max_{a'}Q(s',a';\theta)$。

**离轨**。训练数据的分布和当前策略不一致，比如用旧策略的数据学习新策略。

单独拿出任何两项，算法通常还能收敛。三项凑齐，就可能发散。

### 为什么会发散

直觉上的解释是，这三件事各自引入了误差，而误差会互相放大。

把这句话说得更具体一点。函数逼近让“改一个参数”等于“改一片状态的价值”，误差有了传播的路径。自举让“当前估计”进入“下一个目标”，误差有了反馈的口子。离轨让数据分布和目标分布不一致，误差有了持续输入的方向。三条路径同时打开，一个小扰动就能绕着圈长大。

自举让误差沿着状态之间的连接传播。函数逼近让一个状态的更新影响到其他状态，可能是远处的、不相关的状态。离轨让数据分布和目标分布错位，更新方向不再是对真实目标的梯度。

三者叠加，就出现了一种情况。参数朝着降低当前样本误差的方向走，但与此同时，目标也在变，而且变的方向恰好让误差变大。追着自己的影子跑，越跑越远。

有一个著名的反例叫 Baird 反例，用线性函数逼近加离轨加自举，构造出一个无论步长多小都会发散的例子。它说明这不是调参能解决的问题，而是算法结构本身的问题。

反例的结构很朴素。七个状态，排成一列。每个状态有两个动作，一个叫虚线动作，固定跳回顶上那个状态；一个叫实线动作，等概率跳到七个状态中的任意一个。奖励全是零，所以真实价值全是零。

函数逼近用八个权重，前七个分别是七个状态的专属特征，第八个是所有状态共用的常数特征。目标策略总是选实线，行为策略大部分时间选虚线。

关键在于那个共用特征。它出现在每个状态的表示里，所以任何一个状态的更新都会改到同一个参数。而目标策略会把状态送到一个混合，行为策略却把大部分时间花在顶上那个状态。两边占的比例不一样，同一个权重在不同位置被推动的方向相反。权重于是分成两组，一组往正无穷跑，一组往负无穷跑，而它们的和，也就是价值估计，一直停在零附近。

这就是发散的典型形态。看价值，它一直是对的；看权重，它在爆炸。只看价值曲线的人根本发现不了，直到数值溢出。用神经网络时这个现象变成另一副面孔，权重不会明确地跑到无穷，而是某些层的激活值变得很大，梯度慢慢失控，最后训出 NaN。

为什么走向相反。把更新写成矩阵形式，每一轮的期望变化是一个矩阵乘上当前权重。发散等价于这个矩阵有绝对值大于一的特征值，而它只由特征、转移概率和折扣因子决定，与权重无关。所以一旦结构上具备这个特征值，再多调步长也无用，因为步长只是把发散的速度变快变慢。

### 半梯度的不动点差在哪

“收敛”这个词在半梯度里要小心。它收敛到的东西，不一定是真值。

$$
w_{t+1} = w_t + \alpha\left[r + \gamma \theta^\top\phi(s') - \theta^\top\phi(s)\right]\phi(s)
$$

把目标也看成参数的函数，严格按平方误差求导应该多出一项，那一项正是“目标也在动”的贡献。丢掉它之后，不动点满足的条件变成“贝尔曼误差在特征空间上的投影为零”。这个条件和“价值误差最小”不是一回事。

差别有多大，可以量一下。五状态随机游走，用两个特征（常数加状态序号），折扣因子零点九。真实价值是零点零六五、零点一四六、零点二五八、零点四二八、零点六九三。

半梯度的不动点给出零点零四五、零点二零一、零点三五七、零点五一三、零点六七零，最大误差零点零九九。最小二乘拟合给出零点零一一、零点一六四、零点三一八、零点四七一、零点六二五，最大误差零点零六七。

两组数都不算准，因为两个特征表达不了五个点的弯曲。但半梯度的误差比最小二乘大了将近一半，均方误差差不多是一点五倍。

这个差距有一个理论界。半梯度的误差不超过最小二乘误差的一除以（一减折扣因子）倍。零点九对应十倍，实测不到两倍，说明上界很宽松。宽松的界在实践中是好事，它意味着半梯度虽然不最优，但通常够用。

还有一个角度能解释为什么半梯度仍然好用。它让贝尔曼误差为零，而控制任务依赖的正是状态之间的一步关系。绝对数值偏一点，只要相对关系对，贪心选择就不会错。

代码上，半梯度和普通回归的差别就一行。

```python
def linear_td_step(w, phi_s, phi_s2, r, gamma, alpha):
    target = r + gamma * (w @ phi_s2)   # 目标里含参数，但不求导
    delta = target - (w @ phi_s)
    w = w + alpha * delta * phi_s       # 梯度就是特征本身
    return w
```

线性模型下梯度就是特征向量，这一行把更新写得非常干净。也正因为干净，可以把它当成基准。换成神经网络时，`phi_s` 由网络的前向计算得到，`w @ phi_s` 变成网络的输出，梯度换成反向传播，其余一模一样。半梯度的概念在两种情况下都是同一个。

### 工程上的三种绕法

既然三要素凑齐会炸，实际做法就是想办法拆掉其中一个，或者削弱它的影响。

**削弱自举**。用目标网络，让目标值在一段时间内固定。这等于把自举的频率降下来，给参数一个稳定的追赶对象。DQN 用的就是这个办法。

目标网络的效果可以从最小二乘的角度看。如果目标固定，每一步就是一个普通的回归问题，最小化它有明确的最优解。目标一直动，每一步追的东西不一样，就变成了追逐。让目标每几百步才动一次，等于把一个动态问题切成很多段静态问题，每段都收敛一点，段与段之间再跳一下。

同步频率的取舍很直接。太频繁，等于没有目标网络；太稀疏，目标过时，学到的价值落后于当前策略。实践中观测值常用的范围是几百到一万步之间，具体取多少和环境有关，回合越长可以取得越大。

**削弱离轨**。把行为策略和学习策略拉近，比如限制探索率，或者用重要性采样修正分布差异。

**削弱函数逼近的影响范围**。用局部化的特征，让一个更新只影响附近的状态。线性模型加合适的特征可以做得好一些，神经网络很难。

还有一类完全不同的思路，放弃价值函数，直接优化策略。策略梯度方法没有自举，天然避开了三要素中的一项。它们有自己的不稳定来源，但性质不同。第三部会讲。

### 怎么判断是哪一条在作怪

训练炸了，三个要素都可能被怀疑。逐个关掉，是不错的排查方法。

先试关掉离轨。把数据改成完全由当前策略产生，回放缓冲区改成只用最新的一批，看曲线是否变稳。变稳了，问题在分布错位。

再试关掉自举。把一步目标换成完整回合的回报，看会不会好转。这个改动会大幅增加方差，所以不能一直用，但作为诊断手段很有效。如果一切正常了，问题在自举。

最后试关掉函数逼近。换成表格，或者把特征数量降下来。这个改动在小环境里可行，大环境里做不了，但至少能告诉你容量是不是问题。

三次实验都不需要改结构，几行配置就能切。比盯着曲线猜快得多。

### 泛化是把双刃剑

函数逼近的好处是泛化。相似的状态给出相似的价值，一个更新能影响一片区域。

坏处也是泛化。它可能把不该联系在一起的状态联系起来，导致一个状态的错误污染另一个状态。更麻烦的是，这种污染在表格方法里不存在，所以从表格迁移过来的人往往没有心理准备。

一个具体的例子。Atari 游戏里，画面变化很小但意义完全不同的两个状态，在像素空间里距离很近。神经网络会把它们当成相似的，给出相似的价值。结果是一个状态下学到的策略，被错误地应用到了另一个状态。

解决方案通常是改进状态表示，让有意义的差异在表示空间里也被拉开。这件事没有通用方法，往往要靠领域知识。

### 泛化过头的几个真实例子

第一个是状态混同。两个局面看上去一样，实际差别在一步之后才显现，比如两个仅差一个计时的库存状态。网络把它们当成同一个，价值被平均，两边都不准。

第二个是奖励泄漏。有些特征在训练集里与高回报相关，但那是数据分布造成的偶然关联。网络学到了这个关联，换一个分布就崩。这是离线数据训练里最常见的一类失败。

第三个是尺度敏感。输入特征的量级相差很大时，网络会把注意力放在数值大的那几维，小的那几维几乎被忽略。表现是“明明给了这个信息，模型就是不用”。遇到这种情况先查归一化，而不是换模型。

第四个是目标不一致。用一批旧策略的数据训练，价值函数会拟合旧策略的价值，而贪心动作要的是新策略的价值。两者差得远的时候，学得越准偏差越大。

### 一个实用的判断

遇到训练不稳定，可以按这个顺序排查。

先确认是不是离轨。如果数据来自旧策略或者别人，离轨程度高，考虑加重要性采样或者干脆改成在轨。

再看自举的频率。目标网络同步太频繁，等于没有；太慢，目标过时。这个参数值得单独调。

最后看函数逼近的容量。网络太大，泛化过度，容易把不相关的状态混在一起；太小，欠拟合。先从小网络开始，够用就行。

### 三个值得监控的量

训练不稳的时候，只看回报曲线得不出结论。三个量比较有用。

第一个是时序差分误差的均值。它应该在一个稳定的范围里波动。持续变大，说明目标在跑；一直不降，说明学习率太小或者特征不够；忽大忽小，说明目标网络或者数据分布有问题。

第二个是参数的范数。发散时它不会平滑地上涨，而是先缓慢上升然后突然加速。看到这个形状，不要去调学习率，先去看特征里有没有那种“每个状态都带”的共用项。

第三个是输出的量级。价值应该和回报同量级。如果价值变成回报的几百倍，肯定是奖励缩放或者自举写错了。这个检查很便宜，每次记录一下最大最小值就够。

这三个量放在同一张图上，能区分三种不同的失败。误差大而参数稳，是欠拟合；参数涨而误差不降，是发散；误差和参数都健康但回报不涨，是探索或者奖励设计的问题。后者不属于三要素的范围，但经常被误判成算法不稳。

### 一个可以自己跑的对照

想亲眼看到半梯度的偏差，不需要复杂环境。用五状态随机游走，特征取常数加状态序号两个，跑线性时序差分，和最小二乘拟合对比。

时序差分的部分只需要几十行，因为它不涉及策略，只是估计。把状态的价值用两个特征表达，跑足够多的回合，权重会稳定下来。再用同一批访问频率算出最小二乘解，两者一比，差距就出来了。

这个实验的意义在于它拆掉了所有干扰。没有神经网络，没有目标网络，没有探索，只剩下“目标含参数但不求导”这一件事。如果在这种干净环境里都能看到偏差，那么深度网络里的不稳定就不再神秘，它只是同一件事被放大了。

反过来说，如果在这个环境里两者一致，也不要急着下结论。表格表示下它们本来就应该一致，因为每个状态可以独立拟合。特征不够用才会分开，所以实验的关键是故意把特征做得不够用。这一点很多教材没有强调，导致读者跑完实验觉得“没什么区别”。

### 从三要素到 DQN

DQN 是这三条绕法的具体实现。目标网络削弱自举，经验回放让数据近似独立同分布，奖励裁剪控制尺度。

它没有从理论上解决发散问题，只是把发散的概率压到了可以接受的程度。这也是深度强化学习的一个特点，很多方法不是证明了正确，而是调到了能用。

最后把这一章和前面接起来。第五章的表格方法有一个隐含的好处，状态之间互不影响。换成函数逼近，这个隔离被打破了，于是所有关于收敛的结论都要重新审。三要素是这种重新审视的结果，它告诉你哪三种情况凑在一起会出问题，以及为什么。

理解了这件事，后面看 DQN 家族就不会觉得那些改动是随意堆的。目标网络在削弱自举，经验回放在打散相关性，double 结构在校正高估，每一项都能对上这里的某个判断。
